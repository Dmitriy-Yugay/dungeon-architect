# Dungeon Architect

A planned dungeon-builder tower defense game built with Kotlin and libGDX.
The player designs a dungeon, places defenses, and survives waves of invading
heroes.

## Status

The project is in the design and architecture phase. No game implementation
exists yet.

## Planned technology

- Kotlin
- libGDX
- Gradle

The first milestone is a desktop prototype of the build-and-defend loop.
